Night Desk Trivia

A trivia game for the Yours Truly, Johnny Dollar 24/7 live stream on YouTube.

What it is

Night Desk Trivia is a small automated chat game that runs during the 24/7 classic detective radio live stream. Every 15 minutes, "The Night Desk" posts a trivia question in the stream's live chat. The first viewer to answer correctly wins a prize of clams.

How it works

Night Desk Trivia uses the YouTube API Services to read the live chat of this one stream and to post messages in it. It checks chat for a correct answer for a short time after each question. When someone answers correctly, it posts the result and pays the prize through the stream's chat bot.

Clams are a just-for-fun chat currency. They have no monetary value and cannot be bought, sold, or exchanged for anything outside the stream.
